This repository was created on 8 September 2026 for CSE 1102 Section 9 in order to learn and practice GitHub, Markdown, version control, and GitHub Pages.
Version Control: Version control helps us track and manage changes in a project.
Git: Git is a tool used to track changes in files and projects.
GitHub: GitHub is a website where we can store and share Git projects.
Git Bash: Git Bash is a program used to run Git commands on a computer.
Main parts of GitHub: The main parts are repositories, branches, commits, pull requests, and issues.
Stages of Git/GitHub: The main stages are working directory, staging area, local repository, and GitHub repository.
